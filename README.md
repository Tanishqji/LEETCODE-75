# LEETCODE-75

This repo is where I'm documenting my attempt at the LeetCode 75 challenge — a curated list of 75 problems covering the key DSA patterns (Arrays, Strings, Two Pointers, Sliding Window, Trees, Graphs, DP, and more).

For every problem I solve, I'm writing up:

Intuition — my first thoughts on the problem
Approach — how I solved it, step by step
Complexity — time and space analysis
Code — the accepted solution

Once I finish all 75, I'll be sharing the full journey on LinkedIn.
